Exile Nexus é um projeto proposto de portal público de apoio a Path of Exile 2.
O repositório ainda não contém a aplicação nem confirma direitos de uso, fontes
de dados, integrações ou implantação.

Consulte o [Source Pack](docs/README.md) para escopo, requisitos, Definition of
Done, hierarquia de fontes, decisões e checkpoint. Estes documentos estão em
proposta nesta Work Order. A matriz de direitos permanece restritiva: nenhum
uso de dados de jogo, API econômica ou monetização foi liberado.

O repositório ainda não contém a aplicação. O baseline inicial está em
[docs/evidence/EXN-M00-WO-001-baseline-2026-11-08.md](docs/evidence/EXN-M00-WO-001-baseline-2026-11-08.md).
