# Exile Nexus

- **Owner:** NexLabsTech
- **Status:** PROPOSED
- **Revisão:** 2026-11-08
- **Work Order:** EXN-M00-WO-006 · Issue #7

Exile Nexus é um projeto proposto de portal público de apoio a Path of Exile 2.
O repositório ainda não contém a aplicação nem confirma direitos de uso,
fontes de dados, integrações ou implantação.

Consulte o [Source Pack](docs/README.md) para escopo, requisitos, Definition of
Done, arquitetura, contratos, plano de deploy, modelo de ameaças, hierarquia de
fontes, decisões e checkpoint. A fundação permanece em construção. A matriz de
direitos não libera dados de jogo, API econômica, árvore passiva ou monetização.
Nenhuma coleta de dados pessoais ou credencial de produção está aprovada.

O repositório não contém aplicação ou deployment. O baseline inicial está em
[docs/evidence/EXN-M00-WO-001-baseline-2026-11-08.md](docs/evidence/EXN-M00-WO-001-baseline-2026-11-08.md).
